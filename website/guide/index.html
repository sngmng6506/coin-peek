몰래코인은 어떤 프로그램인가요?

몰래코인(Coin Peek)은 일하는 중에도 창을 바꾸지 않고 관심 코인 시세를 확인할 수 있게 만든 무료 Windows·Mac 데스크톱 위젯입니다. 주식 버전인 몰래주식과 같은 방식으로 동작합니다.

한 문장으로 답하면

화면 오른쪽이나 왼쪽 끝으로 마우스를 가져가면 업비트·바이낸스·bitbank 관심 코인의 시세, 최근 90일 흐름과 평가손익이 나타나는 무료 오픈소스 Windows·Mac 위젯입니다.

핵심 기능

  • 화면 가장자리로 마우스를 가져가면 패널이 나타나고, 커서를 옮기면 자동으로 숨겨집니다.
  • 업비트 원화(KRW) 마켓은 한글·영문 이름과 티커로, 바이낸스 USDT 마켓은 티커로, bitbank 엔화(JPY) 마켓은 티커와 일본어 이름으로 검색합니다. 바이낸스와 bitbank 검색 결과는 거래대금 순입니다.
  • 보유 수량(소수점 여덟 자리까지)과 평균 매입가를 넣으면 평가손익을 함께 보여줍니다.
  • 소액 코인은 유효숫자 네 자리까지 표시합니다(예: $0.00000485).
  • 최근 90일 일봉을 작은 차트로 보여줍니다.
  • 화면 왼쪽·오른쪽과 여러 모니터 중 원하는 위치에 패널을 둘 수 있습니다.
  • 시스템 트레이(Mac은 메뉴 막대)에 상주하고 컴퓨터를 켤 때 자동 실행할 수 있습니다.

설치하고 사용하는 방법

  1. 설치 파일 내려받기: 이 페이지에서 최신 설치 파일을 내려받아 실행합니다. Windows는 .exe, Mac은 .dmg입니다.
  2. 관심 코인 추가하기: ＋ 버튼을 누르고 업비트, 바이낸스, bitbank 중 하나를 고른 뒤 코인 이름이나 티커로 검색해 추가합니다. 필요하면 보유 수량과 평균 매입가도 입력합니다.
  3. 화면 가장자리에서 확인하기: 화면 가장자리로 마우스를 가져가면 패널이 나타납니다. 커서를 다른 곳으로 옮기면 자동으로 숨겨집니다.

개인이 개발한 앱이라 코드 서명이 없어 Windows SmartScreen 경고가 뜰 수 있습니다. “추가 정보”를 누른 뒤 “실행”을 고르면 설치됩니다. Mac은 Apple 공증이 없어서 처음 열 때 차단되면 시스템 설정 → 개인정보 보호 및 보안에서 “그래도 열기”를 누르면 됩니다.

시세 출처와 갱신 주기

업비트, 바이낸스, bitbank가 공개한 시세 API에서 직접 가져옵니다. API 키나 거래소 계정은 쓰지 않습니다. 코인은 24시간 거래되므로 언제나 3초마다 갱신하고, 같은 거래소의 코인은 한 번의 요청으로 묶어서 가져옵니다.

등락률 기준이 거래소마다 다릅니다. 업비트는 전일 종가(한국 시간 0시) 대비, 바이낸스와 bitbank는 24시간 전 대비입니다. 차트는 모두 최근 90일 일봉입니다.

개인정보와 로컬 저장

거래소 계정에 로그인하거나 주문 기능과 연결하지 않습니다. 관심 코인, 보유 수량, 평균 매입가, 언어와 패널 위치 같은 설정은 사용자의 PC에 저장됩니다. 자세한 내용은 개인정보 안내에 있습니다.

자주 묻는 질문

몰래코인은 무료인가요?
네. 앱 안에 광고, 결제, 회원가입이 없고 전체 소스 코드는 MIT 라이선스로 공개되어 있습니다.
어떤 코인을 지원하나요?
업비트 원화(KRW) 마켓, 바이낸스 USDT 마켓, bitbank 엔화(JPY) 마켓에 상장된 코인을 지원합니다. 상장폐지되거나 거래가 멈춘 코인은 조회되지 않습니다.
주식도 볼 수 있나요?
주식은 같은 개발자가 만든 몰래주식에서 볼 수 있습니다. 두 앱은 따로 설치하고 따로 동작합니다.
회사 PC에서도 사용할 수 있나요?
시스템 프록시와 인증서를 사용하지만, 회사 네트워크가 거래소 사이트를 막아 두었다면 시세를 가져올 수 없습니다.
표시되는 시세로 거래해도 되나요?
표시되는 시세는 공식 체결 데이터나 투자 조언이 아닙니다. 거래 전에 거래소에서 최신 시세를 다시 확인하세요.
