How updates work

The app checks for a new version at launch, every hour after that, and when the panel opens (at most every 15 minutes). On Windows it downloads in the background and shows a notification; click it to install and restart. Mac builds are unsigned and cannot install themselves, so the notification opens the download page.

Requirements and notes

  • Windows 10 or 11, macOS 12 or later
  • Needs an internet connection; networks that block exchanges will not show prices.
  • Not code-signed: Windows SmartScreen may warn, and on Mac the first launch must be allowed in System Settings.
  • SHA-256 checksums are attached to each GitHub release.
