화면 가장자리에 마우스를 대면 관심 코인 시세가 나타나는 Windows·Mac 위젯. [몰래주식](https://github.com/sngmng6506/stock-peek)의 코인 버전.

## 설치

- [Releases](https://github.com/sngmng6506/coin-peek/releases/latest)에서 Windows는 `coin-peek-setup.exe`, Mac은 `coin-peek-mac.dmg`
- Windows는 앱 안에서 자동 업데이트, Mac은 새 버전 알림 후 직접 내려받기
- Mac 첫 실행: 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기" (Apple 공증 없음)

## 기능

- 가장자리 hover로 패널 표시·자동 숨김, 좌·우 배치, 멀티모니터
- 업비트(KRW)·바이낸스(USDT) 코인 검색. 업비트는 한글·영문 이름, 바이낸스는 티커
- 보유 수량(소수 8자리)·평균 매입가 입력, 평가손익, 90일 일봉 차트
- 소액 코인은 유효숫자 4자리까지 표시 (0.00001234)
- 등락률: 업비트 전일(한국 시간 0시) 대비, 바이낸스 24시간 대비
- 드래그 정렬, 한국어·English·日本語·العربية, 트레이 상주, 시작 시 자동 실행
- 24시간 3초 갱신, 오류 시 마지막 시세 유지
