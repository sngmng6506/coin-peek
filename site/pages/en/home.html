FAQ

Windows shows a warning when I install it.
The app is not code-signed, so SmartScreen warns about it. Click “More info” → “Run anyway”. You can also read the source on GitHub and build it yourself.
Where do the prices come from?
Directly from the public market data APIs of Upbit and Binance, refreshed every 3 seconds. Upbit’s change is against the previous close (00:00 KST); Binance’s is against 24 hours ago.
Does it work on a work computer?
It uses the system proxy and certificates. Many companies block exchange sites, though, and if Upbit or Binance is blocked on your network, prices will not load.
How do I install it on a Mac?
It runs on macOS 12 or later. Open the downloaded file and move the app to Applications. It is not notarized, so if macOS blocks the first launch, click “Open Anyway” in System Settings → Privacy & Security. Mac has no automatic install; when a new version is out, click the notification and download it again.

Installation and detailed usage are in the guide.
