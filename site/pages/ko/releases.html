자동 업데이트 방식

앱은 시작할 때, 그 뒤 1시간마다, 그리고 패널을 열 때(15분에 한 번까지) 새 버전을 확인합니다. Windows는 새 버전을 백그라운드에서 내려받은 뒤 알림을 띄우고, 알림을 누르면 바로 설치하고 다시 실행합니다. Mac은 서명이 없어 자동 설치가 안 되므로 알림을 누르면 다운로드 페이지가 열립니다.

지원 환경과 주의사항

  • 지원 운영체제: Windows 10·11, macOS 12 이상
  • 인터넷 연결이 필요하고, 거래소 접속을 막아 둔 네트워크에서는 시세가 나오지 않습니다.
  • 코드 서명이 없어 Windows SmartScreen 안내가 뜰 수 있고, Mac은 처음 실행할 때 시스템 설정에서 허용해야 합니다.
  • 파일 확인용 SHA-256 체크섬은 GitHub 릴리스에 함께 있습니다.
