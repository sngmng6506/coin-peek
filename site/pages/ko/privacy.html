몰래코인 / 개인정보 안내

개인정보 및 데이터 처리 안내

몰래코인은 회원가입이나 거래소 계정 연결을 요구하지 않습니다. 관심 코인과 보유 정보는 사용자의 PC에만 저장됩니다.

사용자 PC에 저장되는 정보

다음 정보는 electron-store로 사용자 PC에 저장됩니다.

  • 관심 코인(거래소와 티커)과 표시 순서
  • 보유 수량과 평균 매입가
  • 패널 위치, 선택한 모니터와 좌·우 배치
  • 언어와 첫 실행 안내 확인 여부

네트워크 요청

  • 시세: 업비트(api.upbit.com), 바이낸스(data-api.binance.vision, 실패하면 api.binance.com), bitbank(public.bitbank.cc)의 공개 시세 API에 직접 요청합니다. 요청에는 조회할 코인 티커만 들어갑니다.
  • 업데이트 확인: GitHub Releases에서 새 버전이 있는지 확인합니다.
  • 사용자 수 집계: 하루 한 번 GitHub 릴리즈의 1바이트 파일을 내려받습니다. 아무 정보도 보내지 않고, 다운로드 횟수만 집계됩니다.

분석 도구나 광고 SDK는 앱에 들어 있지 않습니다.
